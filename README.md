# swiftprime-website

Website for swiftprimedesign.com.

- **Edit text and images:** log in at https://app.pagescms.org with GitHub and open this repository. Every save publishes automatically through Netlify (about 1 minute).
- **Content file:** `src/_data/site.json`
- **Layout:** `src/index.njk`, styles in `src/css/site.css`
- **Build:** `npm install && npm run build` (Eleventy) → `_site/`
- Fonts: Geist and Geist Mono, SIL Open Font License, self-hosted in `src/fonts/`.
